# Feature and workflow inventory

The current disposable-profile inventory contains **318 API operations, 21 node types, 10 registered template/legacy workflows, 17 cloud provider definitions and 5 research engine factories**. See [API inventory](evidence/2026-10-25/inventory-summary.json) and [workflow CSV](evidence/2026-10-25/workflow-inventory.csv). Private user projects and graphs were not copied.

Inventory means discovered, not executed. Each registered workflow remains explicitly UNVERIFIED until its nodes, edges, tools, failure paths, provider calls and persisted artifacts have executed with independent assertions. Selected native mission journeys exercise L1–L4; that does not qualify every registered visual/legacy workflow.

Surfaces under test include chat and multi-turn context, library, missions, harness, 3D office, provider launch, shared settings/locale and CLI. A complete control/route/viewport mapping is still open. Use `tools/qa_harness.py inventory` after registering new routes, node types or engines.
