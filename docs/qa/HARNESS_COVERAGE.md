# Harness coverage

The harness separates executable application missions from visual graph control flow, catalog entries and benchmark integrations. An installed Python package is not an executable benchmark adapter. Unimplemented lm-eval/Inspect/promptfoo/ragas/SWE adapters now return BLOCKED/UNSUPPORTED with no fabricated measurements.

Generated graph testing executes 100 valid and 100 dangling-edge validator cases with seed 20261024. It qualifies the schema oracle, not scientific execution. The [workflow inventory](evidence/2026-10-25/workflow-inventory.csv) lists each graph as UNVERIFIED until full execution evidence exists.

Selected browser missions and the Golden Thread execute real processes and persist results. Golden Thread independently recomputes raw measurements and compiles a paper; model-produced prose is advisory. Legacy replay bundles without an executable protocol cannot pass scientific verification.

See [release readiness](RELEASE_READINESS.md) for measured production coverage. Node registration, schema validation and test count alone cannot satisfy the 100% target. New node adapters require real execution, cancellation, authorization, malformed-result and artifact-lineage cases.
