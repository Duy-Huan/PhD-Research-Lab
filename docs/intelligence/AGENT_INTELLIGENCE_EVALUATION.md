# Agent intelligence evaluation

Confirmed behavior improvements are bounded and testable: ordinary reasoning remains permitted without stored experiments, explicit no-tools requests are honored, unrelated chat context is excluded, current-session references resolve correctly, equal-timestamp retrieval is stable and failed partial provider output remains failed.

The Golden Thread's actual Spark response identified 128 samples, noise sigma 0.25 and the pinned 2-second CPU budget with source IDs. The CPU process, independent recomputation and paper compiler—not the model's prose—establish the fixture measurements.

No experiment demonstrates a 50–60% cognitive-load reduction or full native-versus-wrapped research intelligence parity. Complex literature synthesis, independent review, all providers and full architectural consolidation remain unqualified. [Release gate](BACKEND_INTELLIGENCE_RELEASE_GATE.md).
