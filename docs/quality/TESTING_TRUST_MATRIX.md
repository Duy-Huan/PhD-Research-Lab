# Testing trust matrix

| Evidence | Actual execution | Supports | Does not establish |
|---|---|---|---|
| Backend gate | Disposable storage and offline unit/integration fixtures | Executed assertions, fault behavior, production code coverage | Live providers, universal ASVS compliance, Linux execution |
| Vitest | jsdom and explicit API fixtures | UI behavior and whole-source TS/TSX coverage | Actual WebGL, browser layout, network stability |
| 2D Playwright | Chromium → isolated HTTP backend → Spark/Codex where specified | Selected interactions, persistence, multi-turn chat, missions | Every control, viewport or vendor |
| 3D Playwright | Real WebGL2 context, pixels and controls | Actual rendered scene, camera/lighting/dock behavior | Hardware GPU performance or every 3D interaction |
| CLI regression | Real Python child → HTTP → Spark | Settings, locale persistence, saved answer and turn state | Interactive terminal layout on every shell |
| CLI provider probes | Installed vendor subprocesses | Inference when an answer actually returned | A detected binary or signed-in status alone |
| Generated graphs | 200 validator cases with expected valid/invalid outcomes | Schema contract behavior | 200 research workflows executed |
| Golden Thread | PDF ingestion, real model, CPU process, fresh replay, independent math, figure, LaTeX compiler | Lineage and reproducibility of an explicit synthetic fixture | Novel finding, peer review or publication acceptance |

Full counts and failed attempts are in [release readiness](../qa/RELEASE_READINESS.md). Unknown model identifiers and token usage stay unknown. Missing credentials, quota and unsupported executors stay blocked.
