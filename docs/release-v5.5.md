# v5.5.0-preview.1 — immutable protocols and bounded measured trials

Prerequisite: v5.4 deterministic mission/approval/recovery contract tests passed (8/8); legacy/context integration 47 tests OK, 1 privilege skip; frontend 94/94 passed. Live external scientific reasoning remains gated. This increment enables a fixed trusted CPU acceptance capability, not arbitrary autonomous research code.

Implemented files: `execution/protocol_contracts.py`, `protocols.py`, `denoising_worker.py`; capability/gateway registration; existing worker restart hook; research API and existing drawer. Scientific protocol fields are immutable snapshots with stable ID, revision/parent, dataset ID/fingerprint, disjoint sample IDs, worker code SHA, baseline, metrics, seeds and resource limits. New intent requires POST of a new revision and fresh approval. A digest-bound protocol approval has a one-use nonce; a separate mission approval binds the exact execution. Reusing the nonce cannot rerun compute.

The built-in non-parametric denoising study generates smooth images with seeded Gaussian noise. Baseline is the actual noisy input. Pre-registered smoothing strengths are evaluated on validation with identical data/seed/worker for every candidate. The train split is reserved and unused by these non-learning filters. Baseline and the validation-selected filter are evaluated once on the held-out test; test results never drive selection. Per-image clean/noisy/predicted arrays and actual MSE/PSNR are retained, hashed, and summarized per seed. Three distinct seeds, positive paired gains and the pre-registered threshold are required for `candidate_improvement`; it is never an accepted scientific conclusion. Intervals are labelled normal approximations, not statistical guarantees with small n.

Limits: one existing CPU slot, 1 process at a time, ≤10 total trial groups including baseline/test, ≤5 seeds, ≤600 seconds controller budget, ≤45 seconds per native subprocess, conservative disk preflight plus observed artifact checks. The worker is a trusted stdlib script launched with argv, `-I`, minimal env and no code from model text. Local Python is not an OS memory/network sandbox; no arbitrary code or external dataset loader is accepted. Input bounds keep this trusted fixture finite. GPU requests are rejected. Docker uses an already installed digest-pinned image with network disabled, read-only root, memory/CPU/PID limits and dropped capabilities; it never pulls images. Live Docker resource/cancellation acceptance remains pending, so the default is Python.

Use Topics → Experiments (`/experiment`): create protocol → review/approve fixed protocol → prepare execution mission → review/approve mission → inspect trial observations. A failed run retains its error/logs/finished trials. Restart marks in-flight runs/trials interrupted; no implicit retry. Independent reproduction uses a fresh explicit protocol approval and a new mission; same snapshot/code/data/seeds are required. Existing custom Python/Docker experiments, ClearML and optional Optuna remain separate existing routes; this trusted fixture does not fabricate a ClearML task ID or start a second tracker. Automatic LLM code generation and general GPU optimization stay disabled.

API: GET/POST `/api/research/topics/{tid}/protocols` (optional `?parent_id=<uuid>` creates a revision); POST `.../protocols/{pid}/approve` `{digest,note}`; POST `.../protocols/{pid}/mission` creates a draft, not an execution. GET protocols also returns persisted run/trial state. Direct protocol mutation is not exposed. Approval cannot silently change dataset, worker, method, baseline, split or metric. ProtocolRef in the mission binds digest and nonce.

Tests: `tools/run_tests.py test_protocols`: **6/6 passed**, with real native CPU runs, matching independent reproduction, multi-seed recommendation gate, duplicate compute rejection, immutable revisions, GPU/budget/split/seed rejection, worker revision mismatch, Topic isolation and interruption history. Reused mission/workspace regression: **32 tests OK, 1 symlink privilege skip**. Native CLI scientific execution, live Docker, custom external datasets, model weight lineage and GPU/SSIM workloads need separate qualification; this preview does not claim those results.

Migration: SQLite 2→3 adds protocol/dataset/run/trial tables, retaining a `research.v2.sqlite3.bak`. Old records remain intact. Stop the app, retain the whole project folder and restore the prior DB backup together with prior code to roll back. Protocol/trial artifacts live in `workspace/research/experiments/<run>/<trial>/`. No experiment measurement is automatically written into trusted project memory.
