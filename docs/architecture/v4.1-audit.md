# PhD Research Lab — v4.1 audit (Phase 0 / M0)

Audit of the repository at `a38e785` (branch `feature/v3.2-research-os`, app version 4.0.0) before the v4.1 upgrade.
Inputs: `Update_new_version_Firewall.md` (secure CLI gateway / context firewall / hybrid control) and
`Update_to_v4.1.0_prompt.md` (workflow orchestrator, model intelligence, Optuna, Ray Tune). The second prompt calls
the target "v3.6" internally; the repository was already at 4.0.0, so this release is **4.1.0**.

## 1. Stack and baseline

| Area | Finding |
|---|---|
| Backend | FastAPI + uvicorn, Python 3.14 venv, one process. Routers `api_v3*.py`; `app.py` 1.3 k lines. Persistence: JSON files per project (atomic tmp + `os.replace`, `memory/store.py`). Streaming: SSE. |
| Frontend | Vanilla JS, one `index.html` (3.5 k lines) + modules in `frontend/app/*.js`, EN/VI dictionary in `i18n.js` (enforced by `tests/test_i18n.py`). No build step, no JS test runner. |
| Tests | stdlib `unittest`, **184 tests, all passing** (4 opt-in live tests skipped). No coverage tool. No frontend tests. |
| Optional deps | numpy, psutil, pydantic, clearml present; **optuna, ray, torch, pydantic_ai: not installed**. |

## 2. AI integrations (as implemented, not as planned)

| Integration | Transport | Notes |
|---|---|---|
| Cloud providers (Anthropic, OpenAI, Gemini, …) | HTTPS APIs (`llm.py`) | a new `httpx.AsyncClient` per call (TLS handshake every time). |
| LM Studio / Ollama | local HTTP (`local_ai.py`, `llm.py`) | load / unload **only manual**; Ollama's own 5-min keep-alive or LM Studio JIT TTL decide residency. Background agents (summarizer, critic, PDF parser, embeddings) leave models in VRAM. |
| Codex / Claude Code / Antigravity / Gemini CLI | subprocess (`gateway/connectors.py`) | **`cwd = project code folder`**, environment = full `os.environ` minus API keys, no time limit inside the connector; a client that disconnects right after `request_started` left the process running (found by a v4.1 test). |
| MCP | JSON-RPC at `/mcp` + stdio bridge | 12 research tools + sandbox tools; container stays up indefinitely. |
| "Pydantic AI harness" | — | **not present** (planned only). |
| Workflow / HPO / model analysis | — | **not present**. |

## 3. Risks found

1. CLI providers could read/write the research project folder (cwd) and inherited every unrelated variable
   (tokens, cloud credentials).
2. VRAM held by idle local models on a 12 GB consumer GPU; GPU runs were refused until manual unload.
3. Orphaned CLI processes after early client disconnect; no connector-level time limit.
4. No orchestration of multi-step research work; no budgets; no approval gates beyond the gateway review.
