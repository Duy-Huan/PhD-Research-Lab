# v6.2 design gate — 2026-10-22

v6.0 commit 312e9b0 adds supervised contracts on the existing worker. Prerequisites: 44 backend tests OK, 97 frontend tests passed, four harness executions including actual CPU reproduction, quota/restart fault fixtures. Native help/version probes are recorded in artifacts/v60/harness.json; they do not establish live inference or subscription billing qualification.

Missing v6.1: no team model, role registry, structured task envelope or owner/verifier assignment. Add a compatibility layer in agent/teams.py and the existing mission contracts, not a new scheduler. Existing mission_tasks/mission_attempts remain the source of task/run state. All roles are logical assignments executed by the same bounded worker; no fictional simultaneously running model agents.

Plan: strict TeamPlan/AgentRole/TaskAssignment/budgets; deterministic single/fixed/adaptive composition from registered capabilities; persisted schema-validated dependency handoffs; independent verification capabilities; observation-based registry statistics; bounded failure replan into a new draft with remaining budgets and fresh approval; Team Monitor and direct controls. Execution stays serial (`max_parallel_tasks=1`) because this deployment has one owned worker and CPU/GPU slots. Parallel role execution remains unqualified rather than spawning uncontrolled loops.

Risk register: owner/verifier self-certification (separate deterministic verification task), permission expansion (role intersection with Mission allowlist), lost handoff (transactional idempotent envelope), duplicated paid work (existing admission checkpoint/reconciliation), replan budget reset (subtract consumed resources and require fresh approval), fabricated performance scores (counts/timestamps only; null opaque usage), mismatched native health (route rechecked at actual admission), misleading benchmarks (same three fixed workflows, raw timings and logical-role counts; no superiority claim).

Baselines: v6.0 harness has literature inspection, federated file reconciliation and generated CPU denoising/reproduction. Extend these exact workflows through single/fixed/adaptive modes and report execution count, elapsed wall time, outcomes, retries, review actions and unknown provider cost. Metadata and workspace content are synthetic; no real model task benchmark is claimed. Add independent verifier only where raw scientific computation/interpretation requires one. General live-provider pilot remains a blocker to stable autonomous release.
