## Phát hiện mở

| Mức | Phát hiện | Khuyến nghị |
|---|---|---|
| Trung bình | API key cloud cũ, token GitHub, secret ClearML plaintext trong `config.json` (từ trước v3.4) | keyring / Windows Credential Manager (v3.5) |
| Trung bình | `mcp.expose_sandbox = true` mặc định → MCP client chạy được code trong workspace | tắt khi chỉ dùng research tools; cân nhắc đổi mặc định ở bản major |
| Thấp | Một token chung cho mọi MCP client; rate limit theo IP (mọi client local trùng IP) | token theo client, rate limit theo session |
| Thấp | `connect(launch=True)` mở terminal bằng `cmd /c start` (chỉ Windows, lệnh cố định từ code) | giữ, không nhận lệnh từ request |
| Thấp | Sensitivity do researcher gán; nội dung *được tóm tắt* từ bản ghi bị chặn (vd. episode chép lại chi tiết) không tự kế thừa phân loại — chỉ id được che | gợi ý phân loại theo liên kết (propagation) ở v3.5 |
