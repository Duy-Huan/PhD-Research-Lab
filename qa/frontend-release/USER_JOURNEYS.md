# Critical User Journeys (J01 – J22) — PhD Research Lab OS

| Journey ID | Title | User Actions | Expected Observable State | Assertion & Verification |
|---|---|---|---|---|
| **J01** | Launch & Project Switching | Click Project badge in Header -> Choose project from list | Active project updates in header badge; library & missions reload; no data leakage between projects | `expect(screen.getByText('Current Project')).toBeInTheDocument()` |
| **J02** | Chat Multi-line & Draft Preservation | Type multi-line prompt (Shift+Enter), navigate to Library tab, return to Chat | Draft text is completely preserved in composer; scroll position intact | `expect(composerInput.value).toBe(draftText)` |
| **J03** | Chat Error Recovery & Reconnect | Send prompt -> simulate 500 error / network disconnect -> click retry | Error badge displayed with human-readable text; retry re-submits without duplicating user bubble | `expect(screen.getByText(/retry/i)).toBeInTheDocument()` |
| **J04** | Chat Rich Markdown, Math & Code | Render response with KaTeX math (`$E=mc^2$`), table, code block | Math rendered cleanly without overflow; code copy button works; no layout clipping | `expect(screen.getByText(/E=mc/i)).toBeInTheDocument()` |
| **J05** | Mission Objective to DAG Generation | Enter research objective -> Click "Create Plan" | Mission DAG appears with nodes (pending, in_progress) and truthful dependency edges | `expect(screen.getByTestId('mission-dag')).toBeInTheDocument()` |
| **J06** | Mission Explicit Human Approval | View pending mission -> Click "Approve" (or "Reject") | Status updates to approved; no silent automatic approval; revision hash matches | `expect(screen.getByText(/approved/i)).toBeInTheDocument()` |
| **J07** | Mission Live Progress Updates | Observe active mission running with tasks completing | Task cards update status reactively via events; progress bar updates without page reload | `expect(screen.getByText(/100%/i)).toBeInTheDocument()` |
| **J08** | Mission Interruption & Restart | Click "Pause" on running mission -> reload page -> click "Resume" | State survives reload; idempotent restart; never re-executes side-effects without authorization | `expect(screen.getByText(/paused/i)).toBeInTheDocument()` |
| **J09** | Team & Role Handoffs | Assign task to Principal Investigator -> hand off to Literature Reviewer | Role assignments traceable; distinct provider tags displayed honestly | `expect(screen.getByText(/Principal Investigator/i)).toBeInTheDocument()` |
| **J10** | Workstream Partition & Dependency Edge | View Workstream Monitor -> inspect edge Task A -> Task B | Truthful directed dependency arrows; status badges reflect execution stage | `expect(screen.getByText(/Dependency/i)).toBeInTheDocument()` |
| **J11** | Cross-Team Handoff & Auto-Ack | Backend emits cross-team handoff event | Handoff badge appears in timeline with automatic acknowledgment receipt | `expect(screen.getByText(/Handoff/i)).toBeInTheDocument()` |
| **J12** | Dispute Finding Resolution | View flagged finding in Evidence Review -> click "Resolve Dispute" | Audit trail records resolution comment; finding status changes to resolved | `expect(screen.getByText(/resolved/i)).toBeInTheDocument()` |
| **J13** | Canonical Output 409 Race Handling | Save canonical output with stale `expected_revision` (simulate 409) | Displays conflict warning modal; prompts user to pull latest revision or force diff | `expect(screen.getByText(/409|conflict|phiên bản/i)).toBeInTheDocument()` |
| **J14** | Scientific Evidence Verification | Inspect artifact card in Evidence Review | SHA-256 hash displayed, trust level badge shown, verify button triggers verification | `expect(screen.getByText(/SHA-256/i)).toBeInTheDocument()` |
| **J15** | Topic Switch During SSE Stream | Start live event stream -> switch active research topic | Old topic events do not paint into new topic views; subscriptions cleanly unbind | `expect(screen.queryByText('old-topic-event')).toBeNull()` |
| **J16** | Reconnect / Backoff During Active Task | Drop SSE connection -> wait for backoff reconnect | Reconnects without duplicate event listeners; active tasks do not duplicate requests | `expect(screen.getByText(/connected/i)).toBeInTheDocument()` |
| **J17** | Unknown Provider Cost Transparency | Open Dashboard metrics for provider with unmetered local CLI | Displays "Unknown / Not provided" instead of fabricated USD 0 or fake quotas | `expect(screen.getByText(/Unknown|N\/A/i)).toBeInTheDocument()` |
| **J18** | Settings & Secret Sanitization | Enter API keys in Settings -> inspect DOM and console logs | Key inputs masked as password; no plaintext API keys in console or error stacks | `expect(screen.getByPlaceholderText(/api key/i)).toHaveAttribute('type', 'password')` |
| **J19** | Keyboard-Only Navigation & Escape | Navigate sidebar, modal, composer using Tab, Shift+Tab, Enter, Escape | Focus rings visible; Escape dismisses modals and restores focus to trigger element | `fireEvent.keyDown(modal, { key: 'Escape' })` |
| **J20** | Empty / Error / Large Dataset States | Load empty library dataset (0 papers) and large dataset (100+ items) | Empty state displays clear call-to-action; large lists virtualize smoothly without lag | `expect(screen.getByText(/Chưa có tài liệu/i)).toBeInTheDocument()` |
| **J21** | Browser Reload & Context Retention | Change active tab to "Library" -> reload page | Active tab, selected project, and active session restored from localStorage | `expect(useUIStore.getState().activeTab).toBe('library')` |
| **J22** | Dangerous Action Explicit Confirmation | Click "Delete Chat Session" or "Delete Project" | Confirmation dialog requires explicit confirm click; cancel aborts safely | `expect(screen.getByText(/Xác nhận xóa/i)).toBeInTheDocument()` |
